# Часть 3. Многопоточная и многопроцессорная обработка данных

## Описание
Модуль реализует гибридный параллельный конвейер обработки данных по шаблону Producer-Consumer:
- **I/O-bound этап**: один поток `Producer` обходит каталог файлов, а несколько потоков `Consumer` параллельно выполняют чтение и декодирование изображений с диска. Синхронизация счетчика обеспечена через `threading.Lock`.
- **CPU-bound этап**: пул рабочих процессов `multiprocessing.Pool` осуществляет аугментацию (повороты, отражения, шум) без блокировки GIL.
