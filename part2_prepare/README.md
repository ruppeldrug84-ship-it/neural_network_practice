# Часть 2. CLI-утилита для препроцессинга и проверки окружения

## Описание
Модуль содержит консольную утилиту на базе `argparse` с двумя подкомандами:
- `doctor`: проверяет окружение (версию Python, установленные пакеты, доступность CUDA через `subprocess.run(["nvidia-smi"])`).
- `prepare`: рекурсивно ищет файлы заданных расширений, нормализует их и экспортирует в формат `.npy` с выводом подробной статистики.

## Примеры запуска
Диагностика окружения:
```bash
python part2_prepare/app/cli.py doctor
